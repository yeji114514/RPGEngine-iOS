# v0.8 Runtime Integration

v0.8 turns the v0.7 boot pipeline into a real native-runtime boundary.

## Execution stages

```text
VXAceProvider
  -> RuntimeResolver
  -> RubyVMAdapter
  -> Ruby Marshal
  -> Scripts.rvdata2
  -> RGSS3 Binding
  -> Database
  -> Map001.rvdata2
  -> Scene_Map
  -> Metal
```

## Important implementation status

The source tree now has explicit arm64 Ruby VM and Ruby Marshal ABI boundaries, but it does **not** contain a fabricated Ruby interpreter. `RubyVMAdapter` is the point where the pinned, legally redistributable Ruby 1.9.x build must be linked.

The same rule applies to RGSS3: the binding must be implemented from the documented API/behavior and tested against owned VX Ace fixtures; proprietary RPG Maker binaries are not copied into this repository.

## What can be tested now

- VX Ace project detection.
- Runtime selection.
- Scripts.rvdata2 and Map001 existence.
- Runtime architecture/version compatibility.
- Native runtime session lifecycle.
- Metal backend remains the rendering target.

5. Decode RPG::System, RPG::Map, RPG::Tileset and RPG::Event.
6. Implement Bitmap/Sprite/Viewport/Tilemap/Window over Metal.
